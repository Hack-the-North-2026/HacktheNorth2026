## Cloudflare - Best Agent with a Brain

Build an agent that does more than chat. We want agents with memory, tools, state, workflows, or real-world actions, powered by Cloudflare Workers. Your agent could help people research, build, coordinate, automate, play, learn, debug, create, or make decisions.

Strong projects will use Cloudflare as the agent’s backend brain: Workers for logic and orchestration, Durable Objects or D1 for state, R2 for files, Vectorize for retrieval, KV for lightweight data, or Queues for background work.

Get started with the Cloudflare Agents SDK: https://agents.cloudflare.com/. Full challenge details: https://hack-the-north-cloudflare-prize.devrel.workers.dev/.

To qualify, your project must use Cloudflare Workers meaningfully as the runtime, backend, or orchestration layer for an agent. Pages alone does not qualify.

Submissions will be judged on agent capability, meaningful Cloudflare usage, creativity, technical execution, demo quality, and real-world impact. Show how your agent plans, remembers, calls tools, and completes tasks for users during demo.
