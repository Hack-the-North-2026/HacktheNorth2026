# Native Share Extension Target

The iOS Share Extension is generated by Expo's `expo-sharing` config plugin.
It accepts one image and opens the Expo Router `/share` handler, which submits the
image to the existing identify API with `origin=ios_share`.

## iOS Setup

- Plugin configuration: `frontend/app.json`
- Incoming-link redirect: `frontend/app/+native-intent.ts`
- Upload handler: `frontend/app/share.tsx`
- App Group: `group.com.fitstealer.app`
- Extension bundle: `com.fitstealer.app.ShareExtension`
- Supported payload: one image

Run `npx expo prebuild --platform ios` or build with EAS after registering the
App Group for the Apple developer team. This does not run in Expo Go.

Video is intentionally not advertised until the Stage 3 video ingest contract
exists. Apps that only share a webpage URL (instead of image bytes) will not show
Fit Stealer as an image destination.

## Android Setup
- Android `RECEIVE_SHARING_INTENT` intent filter configuration in `AndroidManifest.xml`.
